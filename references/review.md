# 返图检查与漂移修正

本文用于检查视频模型或图像模型返回的实际结果，并写出定点修正。

**只检查实际拿到的画面。** 没有返图时只给提示词或相关检查点，不宣布通过。看不到的部分如实记为未检查，不以提示词已写明作为通过依据。

**用户口述返图内容时**：可以据其陈述写修正，但要标明来源是用户观察而非本方核对，并把未经本方观察的部分记为未检查。不要把用户的描述转写成"我检查后发现"。

## 题材适配检查

资产图、首尾帧和视频返图先对照 [题材与设计依据](asset-chain.md#题材与设计依据)：核对人物服饰与身份、场景建筑与生活或技术条件、道具形制与工作方式是否符合已确认的题材、时代和世界规则。用户明确设定的混搭与例外按记录核对；媒介或配色一致不代表设计符合题材。

缺少设计依据或相关部位不可见时，对应项记为 `UNKNOWN`。发现冲突时指出具体设计差异及其依据，不只写“题材不符”；已锁定设计需要调整的范围单独记录。

## 四个检查轴

按任务取相关的轴，不逐项套用。全局天气变化会改变大量像素，换机位会改变地标的画面位置——检查要针对本次任务。

### 结构

固定机位下核对：建筑轮廓、门窗位置、地标尺度、道路与通路连接、透视、画幅、取景边缘、未受本次变化影响的人物与物件。

换机位时核对的是有依据的空间关系和新露出的设计，**不是相同的画面位置**。遮挡关系改变属于正常。

### 连续性与证据专项

涉及重复地点、连续状态或换机位时，先对照[场景连续性与证据记录](scene-continuity.md)，再检查返图。核对的不是“像不像上一张图”，而是本次使用的来源版本、当前已采纳状态和证据边界是否被遵守。

| 项 | 怎么核对 |
| --- | --- |
| 来源版本 | 是否使用了本次指定的编辑对象和当前版本；旧底图有没有把已移除的物件、人物、招牌或损坏状态带回来 |
| 当前状态 | 已采纳的天气、灯光、损坏、服装和道具状态是否继承；独立变体有没有误继承另一条分支的状态 |
| 证据等级 | 画面中新增的结构是否区分为已观察、用户指定、推断或未知；推断内容有没有被误写成确定事实 |
| 采纳状态 | 未被用户采纳的返图新增内容有没有进入后续提示词、地点记录或资产版本 |
| 新机位关系 | 建筑连接、道路、相对尺度和当前状态是否成立；允许画面位置、透视和遮挡关系随新机位改变 |
| 状态时间轴 | 场景损坏、天气、灯光和门窗状态是否记录了 `effective_after_shot`；变化镜头的首帧是否仍是变化前状态，尾帧是否写结束状态，下一镜是否切换新版本 |
| 采纳后登记 | 用户采纳的新道具、地标或人物是否重新进入镜头清单和资产×镜头交叉表，并按 A/B/C 规则重算 |

看不到来源图、当前版本或连续性记录时，相关项目记为 `UNKNOWN`，不能以提示词中写过为通过依据。发现状态回滚或证据越界时，先恢复正确来源版本，再只修正本次变化。

### 扩图专项

扩图返图先与扩图前的原图并排核对，再检查新增区域。扩图改变了画布范围，不应借此重排原区域或把扩图误判成换机位。

| 项 | 怎么核对 |
| --- | --- |
| 原区域尺度 | 原图区域内的头部大小、肩宽、人物体型、建筑尺度和镜头距离是否保持；没有为填满新画布而缩放、拉伸或压扁原内容 |
| 边缘接续 | 原裁切边与新增区域是否连续，纹理、衣物结构、地面、墙面、植被和遮挡是否无拼接缝、重复纹样或材质跳变 |
| 透视与光照 | 新区域是否延续原透视、地平线、光源方向、景深和阴影逻辑；扩图没有偷偷改变机位 |
| 自然边界 | 人物是否停在要求的半身或原本已有依据的边界；没有因为选区过大而补成全身或继续添加不需要的身体部位 |
| 设定板边界 | 对照 [扩图与画幅延展](outpainting.md)，区分仅扩展画布与有依据的裁切修补；左侧颈部裁切和头部留白保持，未被当作缺失内容补回头部、头发或发饰 |
| 凭空内容 | 是否凭空增加了人物、道具、建筑、文字、装饰或背景地标；只允许补与裁切结构直接相连且有依据的内容 |
| 当前状态 | 雨夜、损坏、伤口、已移除物件和服装状态是否从扩图前的有效版本继承；扩图没有恢复旧状态 |

如果扩图前的原图或选区不可见，只能把上述项目记为 UNKNOWN，不能以提示词写明作为通过依据。发现问题时先判断它属于原区域漂移、边缘接续失败、透视错误还是内容误补，再给局部修正；不要把扩图结果自动登记成新资产。

### 身份

逐个有名角色核对：脸、发型、体型比例、服装结构与层次、配色、识别性配饰。

检查人物设定板时，对照 [设定板统一格式](asset-chain.md#视频参考设定板的统一格式)：默认 16:9 纯白底，左侧约 55% 为颈部至脚部的正、侧、背服装三视图，整个头部省略，原本头部位置留白，身体宽高关系、对应解剖高度和接触基线一致；右侧约 45% 为四头像，正常展示脸、头发和识别性发饰。左侧按展示裁切核对身体与服装，脸和发型在右侧核对。

两个以上**有名角色**同框时逐人核对，因为**身份相互污染是真实失败模式**——两个角色的特征可能互相渗透。无名群演（C 层）不核对身份，只核对人数与大致形貌是否符合要求。

核对身份时看的是可辨识特征是否稳定，不做骨骼测量。对"颧骨宽度""颅骨比例"之类的判断属于模式匹配，不是测量，不要写成测量结论。

### 状态与融合

核对本次要求的变化是否发生，以及已确认的继承状态是否保留：人物、道具、天气、灯光、损坏、已移除的物件。

允许本次变化的必要后果：夜晚改变照明与曝光，雨改变湿度反射与能见度，雪改变覆盖，入画人物改变局部阴影遮挡。这些是变化应有的连带效果，不算漂移。

人物入景另核对：共同光源方向、环境反射、接触阴影、尺度与透视是否一致，有没有抠图感或悬浮感。

### 画风

核对媒介、材质表现、完成度是否与来源兼容。颜色接近或风格相似不足以证明是同一地点或同一角色。

未要求改变画风时，画风变化属于漂移。

## 首帧专项

首帧合成有几个已知高频失败项，逐项放大核对：

| 项 | 怎么核对 |
| --- | --- |
| 设定板转换 | 对照 [首帧合成](asset-chain.md#首帧合成) 的分区职责，按本镜景别核对入画的身体、服装、脸和发型；设定板的分栏、多视图、背景、颈部裁切和头部留白未被误用为本镜画面依据 |
| 肢体数量 | 放大数手臂与腿，确认没有多出 |
| 左右关系 | 对照剧本要求的那只手，确认在画面里的实际位置 |
| 持有关系 | 握持部位、握法、另一只手在哪 |
| 门窗开向 | 对照场景板确认的朝向，内开还是外开 |
| 画内文字 | 有没有不该出现的标牌、字幕、水印 |

左右手与门开向是已知的高失败项，写明在提示词里也可能出错。

修法按错误类型分：左右手这类画面内的左右镜像错误可以用水平镜像修，但要记录它同时翻转了合页、纹样和配饰的左右。门开向是进深方向的错误，镜像改不了，只能定点编辑。任何修正都要记录来源、操作与它改变的设计事实。

## 视频专项

视频返图同样要走上面的四轴和首帧专项——左右手、持有关系、门开合这些在视频里一样会错。下面是只在视频上才有的检查项。

**检查视频返图前先取该镜首帧比对。** 首帧已经错了，和首帧正确但生成过程改写了它，是两类问题，修法不同。看不到首帧时归因记 UNKNOWN。

- **字幕**：写了"无字幕"仍可能烧入字幕。有对白的片段必须检查。
- **切镜处的重建**：纯文字生成在切镜后容易重建空间与人物外观。景别大幅变化时模型会补画首帧以外的区域，补出的内容可能与已确认设计冲突。需要空间稳定时把该镜作为独立生成任务，用资产图为它单独合成首帧。
- **末帧接续**：用上一段末帧作下一段首帧时接缝一致，但**末帧里的错误会被继承**。接续前先检查末帧，有错先修末帧或重做上一段。
- **声音**：能听才说听过。只能看频谱时记明只判断了有无与时段，没有确认字词。

## 修正写法

修正路径先按返图类型分：

**图像返图**：可以定点编辑，从当前图出发改局部。

**视频返图**：画面不可定点编辑，所以修正链是"修首帧 → 重跑该镜"。先判断错误是首帧带来的还是生成过程产生的：
- 首帧就错（如首帧里已经是右手持物）→ 修首帧，再用修好的首帧重跑该镜。
- 首帧正确但视频里改了 → 首帧无需改，调整镜头提示词中对应的描述后重跑；若反复出现且属已知失败项，考虑拆镜或缩短片段。

下面的局部/大面积区分适用于两类返图。

**局部错误**：从当前返图出发，只写观察到的差异与要修的部分，保留其余已确认内容。不重述整个场景设计。

**大面积漂移**：建议回到上一个合适版本，并把仍然需要的已确认变化显式重新声明。不要静默丢弃当前已采纳的状态。

**一次改一个主要变量**，便于判断是否有效。确有依赖关系的变化可以成组，记录缘由。

重试次数不是根因证据。不设"失败几次就必须简化"的规则；需要简化时仍保护台词、结果、边界与已确认条件。

## 归因

记录时区分几类来源，不把全部问题归给模型：

| 来源 | 判断依据 |
| --- | --- |
| 分层或资产缺失 | 该资产本该出图但没出，或该锁定未锁定 |
| 槽位规划 | 超限、互斥规则违反、上传顺序错 |
| 提示词 | 该写的事实没写，或写了相互矛盾的要求 |
| 输入素材 | 传错图、传错顺序、图本身有错 |
| 首帧 | 首帧画面本身就不符合要求 |
| 视频生成 | 首帧正确，但生成过程改写了它已确认的事实 |
| UNKNOWN | 没看到实际输入或首帧，无法定位 |

没看到实际提交的输入时只能提出归因假设，不写成结论。区分"首帧"与"视频生成"必须看到首帧，否则记 UNKNOWN。

## 边界

**检查不是验收。** 本文给的是观察方法。局部通过只适用于已检查的版本和范围。

**没有自动一致性度量。** 身份一致性靠人眼核对，没有嵌入距离或相似度分数。不要给出"一致性 9/10"这类看似量化实则无标准的结论。

**视频总长符合预算不证明内容正确。** 不证明台词没漏、口型同步或接触过程成立。

**地标被特写裁掉、人物被遮挡或暂在画外，不能据此断言物件消失。**
