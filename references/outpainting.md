# 扩图与画幅延展

本文处理已有图片的裁切补全、画幅扩展和场景边缘延展。扩图是对当前图像边界的连续补全，不等于换机位，也不等于重新设计一张同地点图片。

扩图结果仍属于原资产的一个版本或编辑结果。除非用户明确要求建立一个新的独立资产，不因画布变宽、补全了身体或露出新背景就新建资产编号。

## 先判断是不是扩图

- **扩图**：镜头和观察方向不变，只补齐被画面边缘裁掉的身体、服装、道具或环境。
- **裁切**：只改变取景范围，不补出原图没有依据的内容。
- **同地点换机位**：观察方向、透视和遮挡关系发生变化，需要按场景连续性处理；新露出的结构属于有依据的空间关系或保守推断，不是沿原边缘继续画。
- **固定机位编辑**：机位不变，只改变天气、灯光、损坏、人物或道具状态。它从当前版本做局部编辑，不自动改变画幅。

用户说“扩成全身”时仍要先看原图是否已经建立了下半身、服装下摆和接触关系。画布大不是补全整个人物的理由。

## 分析实际图像

收到图片后按以下顺序记录，没看到的部分标为未检查：

1. 识别人物、脸、发型、服装层次、姿态、道具、场景和构图。
2. 记录实际媒介、材质表现、颜色、光照、景深、机位、透视和主体在画面中的尺度。
3. 逐边检查，只写确实被裁掉的结构；不要把画外区域想当然地补成完整姿势。
4. 为每条边选择最近的自然停止边界。

自然边界的默认判断：

- 胸口、腰部或大腿被裁切时，优先补相邻的躯干、手臂、衣襟、腰带、衣摆和必要背景，停在合理的半身或原本已建立的身体边界。
- 只裁到袖口、斗篷边、道具或背景时，只补对应局部，不顺带扩展整个人物。
- 空场景或设定板向外扩时，新增区域只延续背景，不移动、放大、复制或重排原内容。

## 扩图要求

扩图提示词必须同时表达这些事实，并按实际图片删去不适用的条款：

- 保留原图的身份、脸、发型、服装结构、姿态、道具关系和已确认细节。
- 保留原图实际媒介、材质、调色、光照方向、景深、镜头距离、透视和原区域尺度。
- 只延展被裁掉的结构和与之相连的背景；不要为了填满选区新增人物、道具、建筑或身体部位。
- 原区域允许占新画布的比例自然变化，不缩放、拉伸、压扁或重新摆放原内容来维持原占比。
- 人物扩图保持头部大小、肩宽、体型比例和接触关系；不要把半身裁切强行补成全身，除非原图已经建立了全身依据。
- 新旧区域之间的纹理、边缘、遮挡、光照和透视要连续，不出现拼接缝、重复纹样、材质跳变或错误的前后关系。

扩图不应静默改变已经确认的状态。雨夜、受伤、已移除的物件、服装破损和场景损坏要从当前有效版本继承；新增状态另走状态版本或固定机位编辑。

## 方法与引擎分工

**Midjourney 扩图**：以当前图作为编辑对象，延续其实际画风和画幅逻辑。提示词写边缘需要补全的结构、保持项和自然停止边界，不把统一 3D CG 默认套到水墨、摄影或其他已有媒介上。Midjourney 的局部重绘和扩图会回到标准分辨率；`--hd` 源图不会让扩图结果自动保持 2048px，需要时另行说明后续放大。

**GPT Image 2 场景扩展**：以当前版本作为编辑对象，其他图片只按职责提供身份、结构或画风参考。用自然语言写原区域的尺度与透视保持、扩展方向、边缘连续性和停止边界；不虚构遮罩、深度控制、三维投影或像素级锁定。扩图任务应沿用当前图的实际媒介，不因默认画风改变而重新风格化。

如果选区大小不确定，先建议较小的自然扩展，检查后再继续。一次只解决主要扩展变量，便于区分边缘问题、透视问题和内容误补。

## 资产登记

扩图完成后，在原资产下增加版本或编辑来源，不创建新的资产 ID。至少记录：

    source_asset     = 原资产 ID
    source_version   = 扩图前采用的版本
    edit_type        = OUTPAINT / FRAME_EXTENSION
    extension_edges  = LEFT / RIGHT / TOP / BOTTOM / CORNERS
    natural_boundary = 本次扩图应停止的位置
    edit_reason      = 裁切补全、横向扩画幅或场景边缘延展
    result_version    = 扩图结果版本
    locked           = YES / NO
    lock_evidence    = 实际返图检查依据

扩图结果只有在实际画面通过检查后才能锁定。没有返图时可以交付提示词和选区建议，但不能写成扩图已完成或已保持不变。

## 交付格式

有实际图片时，按以下顺序交付：

1. 中文说明：可见裁切、需要补的边、自然停止边界。
2. 一条可复制的扩图提示词；每个引擎或每个版本单独成块。
3. 选区建议：不确定时优先较小扩展，并说明下一次检查点。

提示词里不写资产编号，编号只放在资产登记和版本记录里。扩图提示词不承诺像素级不变、精确恢复不可见结构或自动保持身份；这些都要通过实际返图检查确认。
