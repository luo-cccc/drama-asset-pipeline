# 短剧资产流水线

这是一套面向短剧和剧情视频的文档型技能包。它把剧本拆成人物、场景和道具资产，决定哪些资产值得做参考图，并规划这些资产如何进入不同视频模型的首帧、尾帧和参考槽位。默认只交付文字、表格和提示词，不生成图片或视频。

## 主流程

```text
剧本盘点 → 镜头清单 → 资产×镜头交叉表 → A/B/C 分层
        → 定画风 → 资产图或可选直出 → 平台路由
        → 首尾帧 → 逐镜提交 → 返图检查
```

扩图、重复地点连续修改、换机位和返图修正是按需分支。它们不改变 A/B/C 的判定顺序；扩图结果归入原资产版本或编辑来源，场景新增事实只有用户采纳后才进入后续记录。

## 核心原则

- **分层看可复现性和出现镜数。** 文字可复现的是 C 层；不可复现且出现至少两镜的是 A 层；不可复现但只出现一镜的是 B 层。完整判定见 [asset-tiering.md](references/asset-tiering.md)。
- **状态沿时间轴管理。** 跨镜持续的淋湿、受伤、损坏等建立版本；表情、姿态、持物手等只属于镜头内容。变化发生在镜头内部时，首帧取变化前状态，尾帧取镜头结束状态，下一镜再切换新版本。
- **视频参考设定板使用固定版式。** 16:9 横版、纯白底，左侧约 55% 为颈部至脚部的服装三视图，省略头部并保留其上方占位；右侧约 45% 为四头像，正常展示头发和识别性发饰。统一身体尺度、弱透视和接触基线。完整格式和 GPT Image 2 次要角色直出分支见 [asset-chain.md](references/asset-chain.md)。
- **平台路由按目标模型执行。** Seedance、Kling、Wan 的参考机制不同，槽位预算、首帧承载和上传顺序以 [reference-budget.md](references/reference-budget.md) 为准。
- **场景事实区分证据。** 地点记录区分已观察、用户指定、推断和未知；当前版本优先于旧底图，未采纳返图中的新增细节不自动进入后续镜头。见 [scene-continuity.md](references/scene-continuity.md)。
- **没有看到画面就不宣布通过。** 提示词写明、图片已生成和图片已实际可读是不同状态，返图检查只依据实际拿到的画面。

## 交付边界

提示词放在代码块中，交叉表、资产登记、槽位映射和检查意见使用表格或缩进块。管理编号只用于账本和映射，不写进给图像模型的提示词。未核实的平台参数、API 字段、像素尺寸或控制工具不写成确定事实。

## 已知限制

- Kling 的参考图上限和 Wan 的参考图张数仍有未取证部分，使用前需要实测。
- 多人同框身份污染、左右手、持物关系和门窗开向仍是高风险项，必须检查实际返图。
- 扩图不保证像素级保持；要检查原区域尺度、边缘接续、透视、自然边界和无依据新增内容。
- 本仓库没有自动一致性评分，也没有真实图片或视频验收结果。文档规则用于规划和检查，不替代实际返图。
